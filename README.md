# SignLens – Real-Time ASL Action Recognition

Real-time American Sign Language recognition using **LSTM action recognition**, **MediaPipe** hand landmarks, and optional **WLASL100** scaling. Supports single- and two-hand signs with a sliding-window pipeline and dynamic labels from `labels.json`.

## Features

- **LSTM-based action recognition** – 30-frame sequences, input shape `(30, 126)` for two-hand (WLASL-ready)
- **Sliding-window inference** – prediction every frame once the buffer is full (step=1)
- **Multi-hand support** – up to 2 hands; features concatenated as `[Left_63, Right_63]` (126-dim)
- **Scale-invariant normalization** – wrist-origin, scale by wrist–middle-MCP distance
- **Dynamic labels** – classes loaded from `labels.json` (add WLASL words without code changes)
- **FPS counter** – on-screen performance monitoring
- **WLASL100 integration** – download and use the top-100-gloss subset from the official WLASL repo

## Quick Start

### 1. Clone and install

```bash
git clone https://github.com/SiD-array/SignLens-RealTime-ASL-Recognition.git
cd SignLens-RealTime-ASL-Recognition

python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

**Note:** Use **Python 3.10 or 3.11** for TensorFlow compatibility (3.14 not yet supported).

### 2. Labels and data

- **`labels.json`** – JSON array of gesture names, e.g. `["Hello", "THANKYOU", "Sorry", "Yes", "No"]`.
- For **WLASL100**, run the download script (see [WLASL100](#wlasl100-subset)) then set `labels.json` to the 100 gloss names.

### 3. Train (if you don’t have a model yet)

```bash
# Optional: extract from ZIPs (if you have ASL_dynamic.zip)
python scripts/setup_dataset.py

# Build 30-frame sequences (reads labels.json)
python extract_landmarks.py

# Train LSTM (saves lstm_model.keras)
python train_lstm.py
```

### 4. Run live recognition

```bash
python main.py
```

Press **Q** to quit. Ensure `lstm_model.keras` and `labels.json` exist.

## WLASL100 subset

1. **Clone the official WLASL repo** (one-time):

   ```bash
   git clone https://github.com/dxli94/WLASL.git wlasl_source
   ```

2. **Download top-100 gloss videos** into your project layout:

   ```bash
   python download_100.py
   ```

   This builds `data/WLASL100_map.json` (if missing) and downloads videos to `data/extracted_dynamic/{gloss}/{video_id}.mp4`. Requires **yt-dlp**.

3. Set **`labels.json`** to the list of 100 glosses (same names as the folders under `data/extracted_dynamic`), then run **`extract_landmarks.py`** and **`train_lstm.py`** for 126-feature multi-hand training.

## Configuration (main.py)

- **`MULTI_HAND`** – `True` for 126-dim two-hand (WLASL); model must be trained with 126-dim.
- **`SEQUENCE_LENGTH`** – 30 frames.
- **`BUFFER_SIZE` / `MIN_AGREEMENT`** – temporal smoothing of predictions (smaller = less lag).
- **`MODEL_TRAINED_HAND`** – `"Right"`; left-hand landmarks are mirrored when needed.
